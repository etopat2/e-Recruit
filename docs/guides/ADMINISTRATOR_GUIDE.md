# Recruitment administrator guide

Administrators configure campaigns as data: dates/timezone, posts/reference prefix, sections, eligibility/selection rules, required documents, hard-copy policy, stages, administrative hierarchy, jurisdictions, regions, centres, sessions and assessment definitions. Save/publish a versioned snapshot only after the four-eyes review; published versions referenced by applications/runs are immutable.

Use role and geographic/task scope together. System administrators maintain technology but cannot verify evidence, score, select or record medical decisions. Never use demo users/policy in production. Before each stage reconcile counts, failed jobs, outstanding offline packs/conflicts, exceptions and audit approval references. Export only for an allowed purpose with masking and expiry.

Official UPS owners must sign campaign rules, geography/centre imports, templates, quotas/tie breaks/skill fallback and override authorities before publication.
